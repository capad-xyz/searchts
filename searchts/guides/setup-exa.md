# Exa (optional search provider)

`searchts search` is keyless DuckDuckGo by default. Exa is an **optional** extra if `EXA_API_KEY` is set. It is not required. It is not how `read` works.

Do not run `searchts install --env=auto` to "get Exa."

Install the package: [docs/install.md](../../docs/install.md)
